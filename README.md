# 비타500 에너지 체험 프로젝트

현재 기본 입구와 park.html은 독서실과 완전히 분리된 놀이공원인 ‘비타500 에너지 파크’입니다. study.html은 원래 독서실, club.html은 별도 클럽 버전입니다. 새 프로젝트를 만들지 않고 기존 이동·카메라·캐릭터·가상 캔·미니게임·Trystero 연결 코드를 재사용했습니다. 놀이공원에 독서실 건물·책상·공부 타이머·복귀 동선은 없습니다. 접속 방과 저장 키도 버전별로 분리했습니다.

놀이공원 검증과 범위는 놀이공원-검증.md를 참고하세요. 아래는 독립 독서실 버전의 기존 설명입니다.

공원을 학생들이 함께 공부하는 3D 독서실로 바꾼 시제품입니다. 기존 캐릭터·키보드/터치 이동·드래그 카메라와 제공된 제품 정면 이미지를 재사용했습니다. 주요 행동은 마시기 / 에너지 만들기 / 캔 꾹꾹 세 가지입니다. 자유 채팅, 캐릭터 꾸미기, 가입 화면을 추가하지 않았습니다.

## 실행
Node.js 20 이상: node start.mjs → http://127.0.0.1:4173
이 서버는 개발용 정적 파일만 제공합니다. 서비스에 별도 운영 서버·데이터베이스·유료 API를 연결하지 않았습니다.

## 체험 설정
dist/study-config.js의 startingCans(기본 3), drowsyAfterMs(기본 12000ms), drinkMs, gameSeconds, feverScore, scorePerCan에서 조절합니다. 졸음·빡공모드와 주황 번개는 게임 연출입니다. 실제 효능이나 지속 시간을 의미하지 않습니다.
빈자리를 선택하면 걸어가 앉고 책 보기·필기 동작을 반복합니다. 잠시 후 졸기 시작하며, 마시기로 1캔을 소비하고 눈을 뜬 뒤 공부를 재개합니다.

## 에너지 만들기
좌우 방향키 또는 캔버스 터치·드래그로 캔을 움직여 갈랑가(+2)를 담고 카페인(-3)을 피합니다. 그림과 이름을 모두 표시합니다. 12점에서 FEVER, 24초 뒤 종료하며 양의 점수 6점당 가상 캔 1개(최대 6개)를 보상합니다. 중도 복귀도 현재 점수로 한 번만 정산합니다. 보유 수량과 기존 자리는 유지됩니다.

## 실제 연결과 시연 구분
Trystero 0.26.0 / WebRTC로 같은 주소의 온라인 방문자끼리 위치·좌석·공부·졸음·마시기 상태와 메모 선물을 실제 동기화합니다. ?room=이름 으로 방을 구분할 수 있습니다. 기본 방 reading-room입니다. 공개 Nostr 시그널링과 STUN을 이용하며, TURN은 설정하지 않았으므로 일부 네트워크는 직접 연결되지 않을 수 있습니다. 소규모 체험용입니다.
시연 학생 3명은 항상 시연 학생으로 표시하고, 선물 창에 시연용 동작임을 명시합니다. 시연 학생의 메모는 이 브라우저에만 표시되며 실제 전송이 아닙니다.

## 선물 처리
실제 방문자에게 80자 이내 메모와 가상 캔 1개를 보냅니다. 전송 중에는 1캔을 예약해 다른 행동으로 중복 소비하지 못하게 하고, 받는 쪽의 수신 확인 뒤 차감합니다. 받는 쪽 책상에는 메모와 캔이 나타나며, 메모 클릭 시 메시지 확인과 1캔 지급이 한 번만 이루어집니다. 동일 전송 ID와 수령 기록으로 재시도·중복 클릭의 중복 지급을 막습니다. 상대가 온라인인 동안만 전달할 수 있습니다.
전달 확인이 끊기면 자동 환불하지 않고 예약 상태로 유지해 중복 지급을 피합니다. 상대의 같은 연결이 살아 있으면 재확인합니다. 서버 보관, 오프라인 전달, 기기 간 재화 동기화, 강한 부정행위 방지는 구현하지 않았습니다. 수량·선물 기록은 해당 탭의 sessionStorage에 보존되며 탭 종료 후 보존을 보장하지 않습니다.
동시 좌석 클릭은 연결된 피어 ID로 결정적으로 정리합니다. 연결이 분리된 동안 서로 다른 점유 상태가 잠시 보일 수 있으며, 연결 후 충돌한 자리는 재선택 안내를 표시합니다.

## 제품 이미지
assets/vita500-energy-front.png는 사용자가 제공한 207×511 정면 원본입니다. 일반 캔과 게임 캔은 슬림캔 비율을 유지하고, 캔 꾹꾹은 해당 표면의 정점과 패키지가 함께 변형됩니다. 뒷면 원본은 제공되지 않아 문구를 임의로 만들지 않았습니다. 고해상도 앞/뒷면 또는 전개도로 교체할 수 있습니다.

## 추가 개선 (2026-11-11)
머리카락을 빈틈 없는 두피와 앞머리로 보완했습니다. 책상·칸막이·복도 벽 충돌과 통로 길찾기를 적용했습니다. 좌측 하단 누적 공부 타이머는 입장부터 기록하고 이 브라우저 localStorage에 저장합니다. 잠시 쉬기와 개인 체험은 시간을 멈춥니다. 휴식 시 복도 의자로 이동하고 공부로 돌아가면 이전 좌석으로 복귀합니다.
소리 ON을 누르면 바흐 BWV846 프렐류드 C장조를 피아노 합성으로 반복 재생합니다. Mutopia Public Domain 악보/MIDI를 사용했으며 녹음 음원은 사용하지 않았습니다. 출처: https://www.mutopiaproject.org/ftp/BachJS/BWV846/wtk1-prelude1/ (Tobias Erbsland, Mutopia-2011/09/12-5). 캔 꾹꾹은 금속성 파열음을 중첩해 눌림 강도에 반응합니다. 음소거는 BGM·효과음 모두 정지합니다.
방명록에서 실제 받은 편지와 수령 상태를 재열람합니다. 첫 열람 때만 가상 캔을 지급합니다. 편지는 현재 탭 sessionStorage에 보관해 새로고침을 견디지만, 탭 종료 후 영구 저장·기기 간 공유·오프라인 수신은 제공하지 않습니다.
추가 검사: node --test tests/navigation-clock.test.mjs

## 롤러코스터 1인칭 POV (2026-11-12)
- `dist/park-pov.js`: 기존 `coasterPoint()` 궤도를 사용하는 캔버스 기반 전용 1인칭 카메라 렌더러. 진행 방향에 따른 시선/기울기, 레일/침목/지지대, 앞자리 차체와 안전바, 원근감과 진행률을 그립니다.
- `dist/park-scene.js`: 탑승 중에만 POV로 전환하고 하차 즉시 기존 공원 카메라로 복귀합니다.
- `dist/park-app.js`: 탑승 도중 드래그로 기존 공원 카메라가 틀어지지 않게 보호합니다.
- 기존 탑승시간(18초), 동선, 친구 위치 동기화, 기타 기능은 유지했습니다. 원본 인스타그램 동영상의 프레임을 추출한 것이 아니라 POV 주행 효과를 자체 구현한 버전입니다.
- 실행: `npm start` 후 `/park.html` 접속 → 롤러코스터 탑승장으로 이동 → `롤러코스터 타기` 선택. 자동으로 POV가 시작되고 종료 시 원래 공원 화면으로 복귀합니다.
